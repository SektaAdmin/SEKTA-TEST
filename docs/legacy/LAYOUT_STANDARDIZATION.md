# Layout Standardization Plan

## Система розташування кнопок і фільтрів

### 1. Топбар (`--topbar-h: 64px`)

**Структура:**
```
┌─────────────────────────────────────────────────────────┐
│ [Заголовок] [Первинна навіг.]    [Вторинні] [Основна]  │
└─────────────────────────────────────────────────────────┘
```

**Ліворуч (`topbar-left`):**
- Заголовок сторінки (h1, 16px, font-weight: 500)
- Первинна навігація (якщо є):
  - DateRangePicker / календар (на `/schedule`)
  - Кнопки назад/вперед для навігації
  - Кнопка "Сьогодні" для поточної дати

**Праворуч (`topbar-right`):**
- Вторинні дії та посилання (без акцентного кольору):
  - Посилання ("Звірка →", "Шаблони" на `/schedule`)
  - Таби (Розклад/Архів)
  - Dropdown меню
- **Основна дія (首)** — самою справа:
  - "+ Нова продажа" / "+ Клієнта" / "+ Заняття" / "+ Тренера"
  - Акцентний колір (var(--accent))
  - Висота: var(--control-h) = 32px
  - Padding: 0 14px

### 2. Фільтр-бар (під топбаром, sticky top: var(--topbar-h))

**Структура:**
```
┌─────────────────────────────────────────────────────────┐
│ [Пошук] [Date Range] [Пресети]    [Clear] [Toggle View]│
└─────────────────────────────────────────────────────────┘
```

**Ліворуч:**
- Пошук (input з іконкою, width 200px, focus → 240px)
- Date range picker / single date picker
- Кнопки пресетів (Today/Week/Month)
- Фільтри-кнопки (halls, trainers, payment methods)

**Праворуч (опціонально):**
- Кнопка "Скинути фільтри" (видима тільки якщо є активні)
- Toggle view (Grid/List, якщо передбачено)
- Export / додаткові дії

### `/schedule` ⚠️ (потребує змін)

**Поточна структура:**
```
Топбар лево:  [DatePicker] [←] [→] [Сьогодні]
Топбар право: [Tabs: Розклад/Архів] [Шаблони] [+ Заняття]
```

**Проблеми:**
1. "+ Заняття" змішана з вторинними діями
2. Таби в топбарі праворуч роблять структуру дуже наповненою
3. "Шаблони" посилання має бути меньше помітною

**Нова структура:**
```
Топбар ліво:  [Розклад] [DatePicker] [←] [→] [Сьогодні]
Топбар право: [Шаблони] [+ Заняття]
```

**Деталі змін:**
- Перенести таби (Розклад/Архів) на **фільтр-бар** або **вверх в окремий табсіт-бар**?
  - **Варіант А**: Таби **над топбаром** (flex-direction: column в main)
  - **Варіант Б**: Таби в **фільтр-барі** (ліворуч)
  - **Рекомендація**: Варіант А — таби логічно розділяють два режими сторінки, не є фільтрами

**Нова иерархия:**
```
┌────────────────────────────────────────────────────────┐
│  [Розклад] [Архів]  ← Таби-сітчер                      │
└────────────────────────────────────────────────────────┘
┌────────────────────────────────────────────────────────┐
│  [DatePicker] [←] [→] [Сьогодні]  [Шаблони] [+ Заняття]│ ← Топбар
└────────────────────────────────────────────────────────┘
┌────────────────────────────────────────────────────────┐
│  [Всі зали] [Зал1] [Зал2]  ·  [Всі тренери] [Т1] [Т2] │ ← Фільтр-бар (лише для schedule)
└────────────────────────────────────────────────────────┘
```

### `/accounting` ✅ (майже коректно)

**Поточна структура:**
```
Топбар ліво:  [Звітність]
Топбар право: [Звірка →] [Звіт по тренерах →]
```

**Проблема:** Посилання praворуч виглядають як вторинні, але це повноцінні розділи.

**Варіант:** Перенести в **sidebar-меню** або залишити як вторинні дії?
- **Рекомендація**: Залишити як є — це хлібні крихти до підрозділів. Вони не должны бути у фільтр-барі.

**Фільтр-бар:**
```
[Сьогодні] [Цей тиждень] [Цей місяць]  ·  [Від] [Дата] [До] [Дата]
```

**Зміни:** можливо перенести пресети вліво, а custom date range — праворуч, розділивши їх дивайдером.

## Рекомендації по імплементації

### Порядок змін:
1. **Фаза 1**: Уніфікувати CSS (створити `.topbarLeft`, `.topbarRight`, `.filterBarLeft`, `.filterBarRight`)
2. **Фаза 2**: Рефакторити `/schedule` (таби, топбар, фільтр-бар)
3. **Фаза 3**: Рефакторити `/settings` (таби, якщо потребує)
4. **Фаза 4**: Перевірити `/accounting/*` (може потребувати уточнень)

### Правила:
- **Топбар** завжди має 64px, sticky з z-index 10
- **Фільтр-бар** завжди під топбаром, sticky з z-index 8
- **Таби-бар** (якщо є) над топбаром, sticky з z-index 11
- **Основна дія** — лише одна, праворуч у топбарі
- **Вторинні дії** — за основною, без акцентного кольору
- **Фільтри** — на фільтр-барі ліворуч, пошук — завжди перший
- **Пресети** — перед custom filters (сьогодні → цей тиждень → цей місяць → custom date)
