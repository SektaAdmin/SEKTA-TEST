## Вердикт Anti-Patterns

**ПРОЙДЕН с мелкими находками.** Страница создана не AI; код показывает осознанную структуру и семантику. Но найдены два известных anti-pattern'а:

1. **Боковые цветные полоски** (lines 115–116): `border-left: 3px solid` на мобильных карточках операций. Это в списке абсолютных запретов Impeccable. Идея (визуальная категоризация) звучит, но реализация совпадает с SaaS/AI-gen playbook'ом. **Рекомендация:** Замените на полную границу, фоновую подсветку или иконку впереди.

2. **Анимация свойства layout** (line 65): `transition: width` на `.filterSearchInput:focus` расширяет инпут с 200px на 240px. Вызывает reflow при каждом focus/blur. **Рекомендация:** Используйте `transform: scaleX()` или удалите анимацию.

3. **Недокументированный цвет warning** (#f59e0b): line 315 fallback-цвет (не в DESIGN.md). Намеренно (amber warning), но нарушает консистентность системы.

## Детальные находки по серьёзности

### [P0] Боковые цветные полоски на мобильных карточках

**Локация:** `app/sales/sales.module.css`, lines 115–116  
**Категория:** Anti-Pattern (Абсолютный запрет)  
**Влияние:** Снижает доверие к системе дизайна. Боковая полоска — иконический знак AI-генерации. Здесь намеренно (различить расход/доход), но техника явно запрещена в Impeccable.  
**Стандарт:** Impeccable Absolute Ban #1 (боковые полоски > 1px)

**Код:**
```css
.cardExpense { border-left: 3px solid var(--danger) !important; }
.cardIncome  { border-left: 3px solid var(--success) !important; }
```

**Решение.** Замените одним из:
- **(A) Полная граница:** `border: 1px solid var(--danger)` (все стороны). Чище, намереннее.
- **(B) Фоновая подсветка:** `background: var(--danger-dim)` (уже есть). Семантична + тонко.
- **(C) Иконка впереди:** Добавьте точку или стрелку в заголовок карточки.

**Команда:** `/impeccable layout`

### [P1] Анимация ширины на фокусе инпута поиска

**Локация:** `app/sales/sales.module.css`, lines 65–67  
**Категория:** Производительность (Layout Thrash)  
**Влияние:** При каждом focus/blur браузер пересчитывает layout (200px → 240px). Частое взаимодействие (фильтр поиска) × reflows = микро-зависания на мобильных или под нагрузкой. Нарушает Impeccable (не анимируйте свойства layout).

**Код:**
```css
.filterSearchInput {
  transition: border-color 0.12s, width 0.12s ease-out;
}
.filterSearchInput:focus { 
  border-color: var(--accent); 
  width: 240px; 
}
```

**Решение.** Используйте `transform`:
```css
.filterSearchInput { 
  transition: border-color 0.12s, transform 0.12s; 
}
.filterSearchInput:focus { 
  border-color: var(--accent); 
  transform: scaleX(1.2); 
  transform-origin: left; 
}
```
Или удалите анимацию (200px → 240px не критична; фокусная граница достаточна).

**Команда:** `/impeccable optimize`

### [P1] Нет ARIA-ролей на табах фильтра

**Локация:** `app/sales/page.tsx`, lines 181–189  
**Категория:** Доступность (WCAG AA)  
**Влияние:** Screen reader'ы не объявляют семантику таб-виджета. Клавиатурные пользователи таб'ируют кнопки, но нет `aria-selected` или `role="tablist"`, чтобы указать активный таб. Нарушает WCAG 2.1 Level AA (1.3.1).

**Код:**
```jsx
<div className={styles.feedTabGroup}>
  {(['all', 'sales', 'expenses'] as FeedTab[]).map(tab => (
    <button
      className={`${styles.feedTab} ${feedTab === tab ? styles.feedTabActive : ''}`}
      onClick={() => handleTabChange(tab)}
    >
      {tab === 'all' ? 'Всі' : tab === 'sales' ? 'Продажі' : 'Операції'}
    </button>
  ))}
</div>
```

**Решение.** Добавьте `role="tablist"`, `role="tab"`, `aria-selected`:
```jsx
<div className={styles.feedTabGroup} role="tablist">
  {(['all', 'sales', 'expenses'] as FeedTab[]).map(tab => (
    <button
      role="tab"
      aria-selected={feedTab === tab}
      aria-controls={`panel-${tab}`}
      className={`${styles.feedTab} ${feedTab === tab ? styles.feedTabActive : ''}`}
      onClick={() => handleTabChange(tab)}
    >
      {tab === 'all' ? 'Всі' : tab === 'sales' ? 'Продажі' : 'Операції'}
    </button>
  ))}
</div>
```

**Команда:** `/impeccable harden`

### [P1] Нет явных лейблов на input'ах фильтра

**Локация:** `app/sales/page.tsx`, lines 193–243  
**Категория:** Доступность (Связь форм)  
**Влияние:** Поисковый инпут (только `aria-label`, нет `<label>`), date picker'ы и `<FilterSelect>` без привязанных лейблов. Screen reader'ы не связывают надёжно лейбл с инпутом. Нарушает WCAG 2.1 1.3.1.

**Код (фрагмент):**
```jsx
<input
  className={styles.filterSearchInput}
  type="text"
  value={searchInput}
  onChange={e => handleSearchInput(e.target.value)}
  placeholder="Пошук за клієнтом..."
  aria-label="Пошук за клієнтом"
/>
```

**Решение.** Используйте явный `<label>` с `for` или оберните в `<fieldset><legend>`:
```jsx
<label htmlFor="search-input" className="sr-only">
  Пошук за клієнтом
</label>
<input id="search-input" {...} />
```

**Команда:** `/impeccable harden`

### [P2] Недокументированный цвет warning (#f59e0b)

**Локация:** `app/sales/sales.module.css`, line 315  
**Категория:** Система токенов (Консистентность)  
**Влияние:** Line 315 hardcoded fallback-цвет `#f59e0b` (Tailwind amber-400) не в DESIGN.md. Слабое влияние (warning намеренен), но нарушает консистентность токенов. При миграции цветов её пропустят.

**Код:**
```css
.depositWarning {
  color: var(--warning, #f59e0b);
  background: var(--warning-dim, rgba(245, 158, 11, 0.1));
}
```

**Решение.** Токен `--warning` уже определён в `globals.css` как `#b87a00`. Fallback должен совпадать:
```css
.depositWarning {
  color: var(--warning);
  background: var(--warning-dim);
}
```
Или просто удалите fallback (токены всегда определены):
```css
.depositWarning {
  color: var(--warning);
  background: var(--warning-dim);
}
```

**Команда:** `/impeccable document`

### [P2] Контраст вторичного текста в таблице

**Локация:** `app/sales/page.tsx` ячейки таблицы (lines 300–325)  
**Категория:** Доступность (Контрастность)  
**Влияние:** Inline-стили `color: var(--text-2)` (#525252) на светлый bg #f5f5f2 дают ~5.4:1 контраст (проходит WCAG AA 4.5:1, но с натяжкой). При бликах или на мобильном читается мутно.

**Рекомендация.** Увеличьте до `var(--text)` (#1a1917) для 7:1+ контраста, или используйте `var(--text-2)` только для третичной информации (подсказки, отключённые лейблы).

**Команда:** `/impeccable audit` (переза пуск после исправлений; измерьте контраст)

**Локация:** `app/sales/sales.module.css`, lines 147–161 и media query line 370  
**Категория:** Адаптивный дизайн (Мобильная юзабилити)

## Паттерны и системные проблемы

### 1. Плотность Anti-Patterns
Два канонических AI-tells (боковая полоска + layout-анимация) на одной странице. Каждый намеренен, но их соседство повышает AI-дух. Исправление обоих закрывает этот вопрос.

### 2. Недиспользование ARIA во всех формах
Таб-виджеты и select'ы без семантических ролей. Поправимо в один pass (`/impeccable harden`), но говорит о долге на других страницах.

### 3. Дрейф токенов (слабый)
Один цвет hardcoded вне системы (#f59e0b fallback). Намекает, что разработчики не полностью приняли философию токенов. Рекомендация: добавить замечание в DESIGN.md («Все цвета должны ссылаться на `globals.css` токены; не hardcode'ить hex fallback'ов»).
